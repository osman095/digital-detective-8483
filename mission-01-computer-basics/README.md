# Mission 1 - Know your computer

## 1. Task / objective
Explain how a computer takes input, processes it, gives output and stores results (IPOS). Also identify hardware and software, and some computer systems around me.

## 2. Work completed
I filled in three tables: one IPOS trace for an activity I actually did, a list of hardware and software I use, and three computer systems from everyday life.

### Task 1.1 - IPOS trace: downloading the assignment PDF from Slack and opening it

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I clicked the download button on the PDF in Slack using the trackpad. | Trackpad |
| Processing | The processor ran the Slack app, sent a request over the internet for the file and kept the downloaded data in memory while it came in. | CPU and RAM |
| Output | The PDF opened and I could read it on the screen. | Display |
| Storage | The file was saved in my Downloads folder. | SSD |

The activity goes from input to output like this: my click tells the CPU what to do, the CPU gets the file from the internet using memory to hold it for a moment, then the file is written to the SSD so it stays there even when I turn the laptop off. The screen shows the result so I can read it.

## 4. My understanding
Every computer works in the same basic cycle: input, processing, output and storage. Hardware is the physical parts I can touch, and software is the programs that tell the hardware what to do. Software can be an operating system that manages everything, an application that I use for a task, or a utility that helps look after the computer. I noticed that things like an ATM or a traffic signal are also computers because they take an input, process it and give an output.
